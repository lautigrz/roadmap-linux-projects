
# Proyectos realizados

Proyectos realizados como parte de la práctica de desarrollo y aprendizaje utilizando los proyectos de [Roadmap.sh](https://roadmap.sh/).

* [Log Archive Tool](https://roadmap.sh/projects/log-archive-tool) — Herramienta CLI para comprimir y archivar logs utilizando Bash.
* [Server Performance Stats](https://roadmap.sh/projects/server-stats) — Script CLI para analizar estadísticas básicas de rendimiento de un servidor.
* [Nginx Log Analyser](https://roadmap.sh/projects/nginx-log-analyser) - Script en Bash/AWK para analizar logs de nginx (IPs, paths, status codes, user agents)
* [SSH Remote](https://roadmap.sh/projects/ssh-remote-server-setup) - Configuracion para conectarse mediante SSH a un servidor externo)
